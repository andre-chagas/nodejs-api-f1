# 🏎️ Formula 1 API

Uma API RESTful leve e rápida construída em **Node.js** utilizando o framework **Fastify**. Este projeto fornece dados atualizados sobre as equipes e pilotos da Fórmula 1.

Excelente projeto para demonstrar a criação de rotas, manipulação de parâmetros e configuração de CORS em uma API backend estruturada.

## 🚀 Tecnologias Utilizadas

- **[Node.js](https://nodejs.org/)** - Ambiente de execução
- **[Fastify](https://fastify.dev/)** - Framework web focado em alta performance
- **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática
- **[@fastify/cors](https://github.com/fastify/fastify-cors)** - Middleware para habilitar requisições cross-origin
